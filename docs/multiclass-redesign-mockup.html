What changed here vs. today

  • Confusion matrix is class_labels[] + matrix[][], not a fixed tp/fp/fn/tn — this component is shared by both the main matrix above and the declined-rows matrix in Selective Prediction.
  • "Optimized for" now appears in Model Details too, and the epoch tabs are generated from whichever best_epochs.* keys the training run actually produced — not hardcoded to PR-AUC / ROC-AUC.
  • Binary derived metrics (Hit Rate, Specificity, FPR) are replaced by a per-class precision / recall / F1 / support table with macro and weighted rollups, once there are more than two classes.
  • Strategy tabs are generated from whatever the backend actually computed — "Detect P0…P3" replaces the hardcoded "Detect positives / Rule out negatives" pair, which only ever made sense for two classes.
